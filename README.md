# Dark_and_Light
KIT ClementineJam Repository

This is a game where you can controll a small creature that can transform between several colour states.
Depending on the current colour of the creature, it can interact with different objects in the environment.

Things that we are currently working on:
-design of our creature and the environment
-movement for the creature
  -standard movement (W,A,S,D)
  -jump (SPACE)
  -colour switch (ENTER)
-music design (different instruments for every colour state)
-level design in godot with one layer per colour state
